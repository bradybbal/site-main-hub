# site-main-hub

一个用于归档和发布多个独立 HTML 页面的通用仓库。

## 项目简介

本仓库主要用于存放和管理各种独立制作的 HTML 页面。这些页面可能包括单页应用、信息展示页、工具页面或其他类型的静态网页资源。仓库本身不针对特定网站或域名，而是作为一个集中的归档与发布点，方便统一维护和版本管理。

## 目录说明

```
site-main-hub/
├── pages/          # 存放所有 HTML 页面文件
├── assets/         # 页面所需的公共资源（如 CSS、JS、图片等）
├── docs/           # 相关文档或说明文件
└── README.md       # 本文件
```

- `pages/`：每个页面可单独存放在子目录中，以页面名称命名，便于区分和管理。
- `assets/`：存放多个页面可能共用的样式、脚本或媒体资源，避免重复上传。
- `docs/`：可放置一些额外的说明文档或项目记录。

## 页面归档说明

本仓库的页面归档遵循以下原则：

- 每个独立页面应包含完整的 HTML 结构，并尽量自包含（资源可引用 `assets/` 目录下的公共文件）。
- 页面之间相互独立，无依赖关系，可单独访问。
- 归档时建议在 `pages/` 下创建对应子目录，并将页面文件及专用资源放入其中。
- 如有必要，可在页面所在目录中添加 `README.md` 说明该页面的用途或使用方式。

## 维护说明

- 本仓库欢迎通过 Pull Request 提交新的 HTML 页面或改进现有页面。
- 提交前请确保页面内容合规、无恶意代码，并遵循基本的 HTML 规范。
- 如需删除或更新已归档的页面，请说明理由并保持仓库历史清晰。
- 仓库维护者会定期检查页面可用性，但不对页面内容的准确性或时效性承担责任。
